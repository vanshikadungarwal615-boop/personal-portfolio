# Personal Portfolio Website

## 📖 Project Overview
This is a multi-page Personal Portfolio Website built using semantic HTML5, CSS3, and JavaScript. The website follows modern HTML5 standards and WCAG accessibility guidelines to provide an accessible and user-friendly experience.

## ✨ Features
- Semantic HTML5 structure
- Responsive design
- SEO-friendly meta tags
- Accessible navigation with ARIA labels
- Keyboard-friendly interface
- Accessible contact form
- Clean and organized project structure

## 📁 Project Structure

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run the Project
1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Navigate through the Home, About, Projects, and Contact pages.

## ♿ Accessibility Features
- Semantic HTML5 elements (`header`, `nav`, `main`, `section`, `article`, `footer`)
- ARIA labels for improved screen reader support
- Proper heading hierarchy
- Keyboard-accessible navigation
- Accessible contact form
- High-contrast, readable layout
